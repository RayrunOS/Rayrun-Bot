# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of
conduct. The full text is published at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Scope

The code of conduct applies in all project spaces — issues, pull requests,
discussions, and other channels used for this project — and when an individual
is representing the project in public.

## Enforcement

Report incidents to the maintainers through GitHub: open an issue, or use a
private reporting channel if GitHub offers one for this repository. We do not
publish a private email address.

Maintainers will review reports on a best-effort basis and will respect the
privacy of the reporter. Responses may range from a warning, to editing or
removing contributions, to banning a participant, following the enforcement
guidelines of Contributor Covenant 2.1.
